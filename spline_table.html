// Design Strategy — When T and L Are Fixed by OEM

Module m — most powerful lever. Larger m grows tooth size, reducing N and redistributing all stresses. Smaller m gives more, finer teeth, lowering Sc and St directly.   N Override — add teeth above the calculated minimum; load spreads across more contact area, reducing Sc and St proportionally.   Class — tighter class (4H) increases t_min and reduces St.   Material — upgrading grade or heat treatment raises all three allowables simultaneously. Often the fastest fix when geometry is locked by OEM package constraints.

Unit Conversions
Tlb·in = TNm × 8.8507
Pd = 25.4 / m
dimin = dimmm / 25.4
Number of Teeth · Shigley's §12 · ANSI B92.1
dmin = ∛(16T / (π × Siallow))
Ncalc = (dmin + 2b) / m
Nnom = max(⌈Ncalc⌉, Noverride)
Geometry · ANSI B92.1-1996 Table 1
D = N × m
Db = D × cos(PA)
Dmajor = D + 2a
Dminor = D − 2b
37.5°: a=0.45m · b=0.795m · h=0.885m
45°: a=0.40m · b=0.670m · h=0.790m
Tooth Thickness · ANSI B92.1 §5 · Table 3
tmax = π × m / 2
Class 4H: δt = 0.035 × m
Class 5H: δt = 0.057 × m
Class 6H: δt = 0.090 × m
Class 7H: δt = 0.145 × m
tmin = tmax − δt
Stress Checks · ANSI B92.1 §6
Si = 16T / (π × Dminor³) [psi]
Sc = 2T / (D × N × h × L) [psi]
St = 2T / (D × N × tmin × L) [psi]
All: T in lb·in · dims in inches
Torsional Stiffness · Shigley's §4-3
J = π/32 × Dminor⁴ [mm⁴]
Krad = G × J / L [Nm/rad]
Kdeg = Krad / 57.296 [Nm/deg]
G=80,000 N/mm² · approx. at Dminor
